# Photo slots

Every photograph on the site is a named slot. To fill one, save the picture in
this folder with the slot name as the file name, for example `home-hero.jpg`.
The site resizes it, serves the right size to each screen and lazy-loads it.

Each empty slot on the site shows its own name and a short brief of the shot it
needs. JPG, PNG and WebP all work. Landscape pictures at least 1600 px wide are best.

Use real photographs of the Gately factory, the retread line, the technicians
and the branded vehicles. Never stock photography.
